# افزونه تبدیل تصاویر به WebP برای وردپرس

**WP WebP Converter Pro** یک افزونه سبک برای تبدیل تصاویر کتابخانه رسانه وردپرس به فرمت WebP است. این افزونه امکان تبدیل خودکار هنگام آپلود، تبدیل دسته‌جمعی تصاویر موجود، جایگزینی لینک تصاویر در خروجی سایت و مشاهده آمار مصرف فضا را فراهم می‌کند.

## امکانات

- تبدیل تصاویر `JPEG`، `PNG` و `GIF` به WebP
- تبدیل خودکار تصاویر هنگام آپلود
- تبدیل دسته‌جمعی تصاویر موجود در کتابخانه رسانه
- نمایش نوار پیشرفت و گزارش موفقیت یا خطای هر تصویر
- تبدیل نسخه‌های کوچک‌شده و thumbnailهای مرتبط
- جایگزینی خودکار لینک تصاویر در محتوای نوشته و تصویر شاخص
- تنظیم کیفیت خروجی از ۰ تا ۱۰۰ (مقدار پیش‌فرض: ۸۰)
- امکان حذف فایل اصلی پس از تبدیل موفق
- نمایش آمار تعداد و حجم تصاویر بر اساس فرمت
- نمایش صرفه‌جویی احتمالی و وضعیت WebP در ستون رسانه‌ها
- استفاده از nonce و بررسی سطح دسترسی مدیر برای عملیات AJAX

## پیش‌نیازها

- وردپرس نصب‌شده و فعال بودن امکان نصب افزونه
- PHP با فعال بودن افزونه **GD**
- پشتیبانی GD از تابع `imagewebp`
- دسترسی نوشتن در پوشه `wp-content/uploads`
- دسترسی کاربر مدیر (`manage_options`) برای صفحه تنظیمات و تبدیل دسته‌جمعی

> اگر `imagewebp` روی سرور فعال نباشد، تبدیل انجام نمی‌شود. در این حالت باید GD را با پشتیبانی WebP روی سرور فعال کنید.

## نصب

### نصب دستی

1. پوشه `wp-webp-converter` را در مسیر زیر کپی کنید:

   ```text
   wp-content/plugins/
   ```

2. از پیشخوان وردپرس به مسیر **افزونه‌ها** بروید.
3. افزونه **WP WebP Converter Pro** را فعال کنید.
4. از مسیر **تنظیمات ← WebP Converter** تنظیمات را باز کنید.

## راهنمای استفاده

### تبدیل خودکار

در صفحه تنظیمات، گزینه **تبدیل خودکار تصاویر هنگام آپلود** را فعال کنید. از این پس تصاویر JPEG، PNG و GIF هنگام آپلود به WebP تبدیل می‌شوند و اطلاعات تبدیل در متادیتای پیوست ذخیره خواهد شد.

### تبدیل دسته‌جمعی

برای تبدیل تصاویر قبلی:

1. وارد **تنظیمات ← WebP Converter** شوید.
2. روی **شروع تبدیل دسته‌جمعی** کلیک کنید.
3. افزونه تصاویر پشتیبانی‌شده‌ای را که نسخه WebP ندارند پیدا می‌کند.
4. تصاویر یکی‌یکی تبدیل می‌شوند و نتیجه هر مورد در نوار پیشرفت نمایش داده می‌شود.

### جایگزینی لینک‌ها

با فعال بودن گزینه **جایگزینی خودکار**، اگر نسخه WebP یک تصویر در پوشه آپلودها وجود داشته باشد، لینک آن در محتوای نوشته و تصویر شاخص با لینک WebP جایگزین می‌شود. فایل اصلی در این حالت الزاماً حذف نمی‌شود.

## تنظیمات

| گزینه | توضیح |
| --- | --- |
| کیفیت تصویر WebP | کیفیت خروجی بین ۰ تا ۱۰۰؛ مقدار ۸۰ تا ۸۵ برای تعادل کیفیت و حجم پیشنهاد می‌شود. |
| تبدیل خودکار | تبدیل تصاویر جدید هنگام آپلود در وردپرس. |
| حذف فایل اصلی | حذف JPEG، PNG یا GIF پس از تبدیل موفق؛ این کار قابل بازگشت نیست. |
| جایگزینی خودکار | استفاده از نسخه WebP در محتوای سایت، در صورت موجود بودن. |

## ساختار پروژه

```text
wp-webp-converter/
├── wp-webp-converter.php          # فایل اصلی و هوک‌های وردپرس
├── includes/
│   ├── class-image-converter.php  # تبدیل تصویر و محاسبه صرفه‌جویی
│   ├── class-bulk-converter.php   # پردازش AJAX تبدیل دسته‌جمعی
│   └── class-statistics.php       # آمار فایل‌ها و حجم مصرفی
├── admin/
│   ├── admin-settings.php         # صفحه تنظیمات پیشخوان
│   ├── css/admin-style.css        # استایل صفحه مدیریت
│   └── js/bulk-convert.js         # رابط تبدیل دسته‌جمعی
└── test-webp.php                  # ابزار بررسی و تست محیط
```

## بررسی و عیب‌یابی

فایل `test-webp.php` برای بررسی پشتیبانی سرور، تنظیمات افزونه، تصاویر بدون WebP و آزمایش تبدیل یک تصویر در نظر گرفته شده است. این فایل را فقط در محیط امن و با دسترسی مدیر استفاده کنید و پس از اتمام بررسی، آن را از ریشه سایت حذف کنید.

## نکات مهم

- پیش از فعال کردن **حذف فایل اصلی** از فایل‌ها و دیتابیس سایت نسخه پشتیبان بگیرید.
- تبدیل تصاویر بزرگ ممکن است به حافظه و زمان اجرای بیشتری از PHP نیاز داشته باشد.
- آمار صرفه‌جویی بالقوه بر اساس برآورد میانگین ۳۰٪ محاسبه می‌شود و نتیجه واقعی هر تصویر در زمان تبدیل مشخص می‌شود.
- افزونه در حال حاضر تصاویر JPEG، PNG و GIF را به WebP تبدیل می‌کند و فایل‌های WebP موجود را دوباره تبدیل نمی‌کند.
